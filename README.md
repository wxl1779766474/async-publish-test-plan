# 视频模板 5.0 · 功能测试范围与排期

可直接编辑的静态排期网页。保留按页面划分的测试范围、独立埋点和异常测试模块，支持文字及天数编辑、自动汇总、搜索、撤销和 HTML/JSON 导出。

本次发布初始数据为 15 个模块、595 个功能点，iOS 17 天、Android 18.25 天；异常测试两端各 1 天。

## 托管

GitHub Pages 使用 `main` 分支根目录，入口为 `index.html`，无需安装依赖或构建。

## 编辑与保存

网页编辑自动保存在当前浏览器中，不会写回 GitHub，也不会自动同步其他访问者。迁移版本已包含发布前确认的浏览器修改。要更新所有人看到的初始版本，需要将当前编辑导出并重新发布；多人实时同步需要另接共享存储服务。
